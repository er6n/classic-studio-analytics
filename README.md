# Classic Analytics for YouTube Studio

Brings back the old analytics page in YouTube Studio instead of the new Insights one.

## Install

1. [Download the zip](https://github.com/er6n/classic-studio-analytics/releases/latest/download/classic-studio-analytics.zip) and unzip it
2. Go to `chrome://extensions` and turn on Developer mode (top right)
3. Click Load unpacked and select the unzipped folder
4. Open YouTube Studio and go to Analytics

Keep the folder somewhere you won't delete it, Chrome loads the extension from there.

Click the extension icon to turn it on or off.

If it stops working, [open an issue](https://github.com/er6n/classic-studio-analytics/issues).

Not affiliated with YouTube.
